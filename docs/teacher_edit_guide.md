# 作品の情報の直し方（佐々木先生へ）

防災行動マップにのっている作品の「出席番号・タイトル・伝えたいこと・場所・いつの行動か・見たハザードマップ」を、先生のPCかiPadで直すことができます。
作品の絵は直せません。

## 1. 管理画面を開く

PC のブラウザ（Chrome・Edge）か、iPad の Safari で、次のアドレスを開きます。

```
https://bo-sci-art.github.io/WSsupportApp_yagami_2026/workshop/present/admin.html
```

防災行動マップの画面の右上にある、小さな歯車（⚙）を押しても開けます。

## 2. 合言葉を入れて入る

1. 千葉からお伝えした合言葉を入れます。
2. 「入る」を押します。

- 学校のみんなで使うPCやiPadでは、「このPCで覚える」にチェックを付けないでください。
- 「合言葉がちがいます」と出たら、もう一度入れ直してください。
- 使い終わったら、右上の「ログアウト」を押してください。

## 3. 直したい作品をさがす

上の検索の欄に、**出席番号（例：4205）** か**タイトルの一部**を入れると、その作品だけが出ます。
「場所」の欄で、場所ごとにしぼることもできます。
「並び順」を「出席番号の順」にすると、4201 から番号の順にならびます。

## 4. 「確認・修正」を押して直す

1. 作品の行のいちばん右にある「確認・修正」を押します。
2. 作品の絵と、今の情報が出ます。直したいところを書きかえます。
   - **出席番号**：4201〜4235 の4けたの数字
   - **タイトル**・**伝えたいこと**：そのまま書きかえる
   - **場所**：3つの中から1つ選ぶ。場所を変えると、地図のピンもその場所に移ります
   - **いつの行動か**・**見たハザードマップ**：あてはまるものに全部チェックを付ける
3. 直したところは黄色になります。

## 5. 保存する

1. いちばん下の「保存する」を押します。
2. 「変更前 → 変更後」の一覧が出ます。まちがいがないか見てから「保存する」を押します。
3. 「保存しました」と出たら終わりです。一覧の「最終修正」に「修正済み」と日時が出ます。

- 赤い文字が出たときは、書いてあるとおりに直してから、もう一度「保存する」を押してください。
  例：「出席番号は 4201〜4235 で入れてください。」
- 直すのをやめるときは「やめる」を押します。直している途中なら「保存せずに閉じますか？」と聞かれます。

## 消すときと、かくすとき

一覧で作品の行を押すとチェックが付きます。下の3つのボタンが使えます。

| ボタン | すること |
|---|---|
| 非公開にする | マップから**かくす**。作品は残っているので、あとで「公開に戻す」で元にもどせる |
| 公開に戻す | かくした作品を、マップにもう一度出す |
| 削除する | 作品を**消す**。**元に戻せません** |

**迷ったときは「削除する」ではなく「非公開にする」を使ってください。** あとで千葉と相談してから消すことができます。

## こまったときは

- 画面が古いままのときは、ページを再読み込みしてください。
- 「通信できませんでした」と出るときは、インターネットにつながっているか確かめてください。
- わからないことがあれば、千葉に連絡してください。
