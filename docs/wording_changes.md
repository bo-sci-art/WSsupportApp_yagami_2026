# 言い換え・ルビの一覧（大人版 → 矢上小版）

- ルビは画面の漢字すべてにつけています。書き方は `漢字{かな}`（`workshop/common/ruby.js` が表示のときに `<ruby>` に変えます）。下の表では読みやすさのためルビを省いています。
- ルビをつけていないもの：児童が書いた文章・ペンネーム、地図のタイルの中の地名、国土地理院の凡例画像（画像なので）、地図の出典表記、避難場所などの施設名（データの名前）、ブラウザの確認ダイアログ（ルビが出せないので、ひらがなで書いています）。
- 保存するデータの値（`field_24` のハザード名、`field_23` の「事前／災害時／復旧時」）は大人版と同じ正式名のままで、画面に出す言葉だけを変えています。
